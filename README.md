# 🏢 PeopleFlow-Enterprise HRMS

A production-ready **PeopleFlow-Enterprise HRMS** built using the **MERN Stack** with modern backend architecture and industry-standard practices. This project is designed to simulate how enterprise HR management systems work, featuring secure authentication, role-based authorization, employee management, attendance tracking, leave management, task assignment, real-time notifications, caching, background job processing, and API documentation.

The primary goal of this project is to demonstrate scalable backend development skills using technologies commonly used in modern software companies.
